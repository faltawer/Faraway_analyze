# FARAWAY Project: Board Game Analysis Toolkit

## Overview  
This project is aimed at creating a data-driven toolkit for analyzing the board game *FARAWAY*. By utilizing computer vision and statistical analysis, we aim to extract meaningful data from game cards, perform in-depth analysis, and formulate winning strategies.  
Work In Progress. /!\

![top_1.jpg](Documentation%2FOutput%2Ftop_1.jpg)

**Happy Gaming and Analyzing!**  

## Requirements

- [Teserract OCR](https://github.com/tesseract-ocr/tesseract)
Make sure that teserract executable is in your `PATH` variable.

## Installation

Run following command to install dependencies:
```batch
uv sync
```

## Usage

Run following command to start the application:
```batch
uv run main.py
```
